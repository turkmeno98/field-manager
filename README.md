# Менеджер полей

Минимальный адаптивный веб-каркас для карты и учёта сельскохозяйственных полей. Интерфейс приложения на русском языке.

## Запуск

Откройте `index.html` в браузере или запустите локальный статический сервер из этой папки, например:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`. Leaflet, Leaflet.Draw, Supabase JS, тайлы карт и шрифты загружаются через CDN, поэтому приложению нужен доступ в интернет.

## Возможности

- `index.html` — семантическая разметка приложения, Leaflet 1.9.4 и Leaflet.Draw 1.0.4.
- `style.css` — адаптивная компоновка, панель инструментов, карта и карточка поля.
- `app.js` — рисование/выбор полигонов, вычисление площади, редактирование атрибутов и операции с Supabase.
- `supabase-config.example.js` — шаблон клиентской конфигурации без ключа.
- `supabase-config.js` — локальный конфигурационный файл; он добавлен в `.gitignore` и не коммитится.

Нажмите «Добавить поле», обведите границу кликами по карте и завершите многоугольник двойным щелчком. Площадь считается по географическим координатам по сферической формуле площади кольца и показывается в гектарах. Поля загружаются из `public.fields`; создание, изменение и удаление отправляются в Supabase. Колонка `geometry` содержит GeoJSON Geometry, а `area_ha` рассчитывается из этого контура. При перезагрузке записи снова читаются из базы.

## Настройка Supabase

1. Скопируйте `supabase-config.example.js` в `supabase-config.js`.
2. В Supabase Dashboard откройте **Project Settings → API Keys** (или **Connect**) и возьмите **Publishable key** с префиксом `sb_publishable_`. Для старых проектов можно использовать публичный legacy `anon` key. Вставьте его в `publishableKey` в локальном `supabase-config.js`.
3. Проверьте, что `public.fields` опубликована в Data API и что выданы необходимые SQL grants и RLS-политики для ролей, с которыми приложение будет работать. Клиентский ключ соответствует роли `anon` для незалогиненного пользователя. Ошибки/ограничения доступа выводятся над картой.

В клиентском коде используется только publishable/anon key. `service_role` и secret key блокируются перед созданием клиента и никогда не хранятся в Git. Publishable key публичен и сам по себе не защищает строки: доступ определяется grants и RLS. Так как приложение сейчас не содержит входа пользователей, политика, разрешающая `anon` менять записи, фактически позволяет посетителям приложения изменять таблицу; перед размещением в открытом интернете настройте осознанную политику доступа и добавьте Supabase Auth либо серверный API.

## Картографические слои

В переключателе Leaflet доступны две взаимоисключающие подложки: **🗺️ Карта** (OpenStreetMap) и **🛰️ Спутник** (EOxCloudless Sentinel‑2 cloudless, слой `s2cloudless_3857`). Существующий слой GeoJSON-полей находится поверх обеих подложек и не удаляется при их переключении. Масштаб показывается в метрических единицах. На узком экране переключатель и масштаб остаются внутри карты.

### Источники и ограничения

- **OpenStreetMap:** тайлы `https://tile.openstreetmap.org/{z}/{x}/{y}.png`; атрибуция OpenStreetMap Contributors отображается на карте. Стандартный tile-сервис OSM предоставляется на условиях best effort без SLA, не предназначен для массовой загрузки, предварительного скачивания или офлайн-пакетов. Соблюдайте [Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/) и [правила атрибуции OSM](https://www.openstreetmap.org/copyright). При росте числа пользователей замените публичный демонстрационный источник на подходящий провайдер или собственный сервис.
- **Спутник:** [EOxCloudless](https://cloudless.eox.at/) через WMTS-совместимый URL вида XYZ: `https://tiles.maps.eox.at/wmts/1.0.0/s2cloudless_3857/default/g/{z}/{y}/{x}.jpg`. Для слоя выбрана мозаика **2016**: EOX указывает для неё лицензию [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), без ограничения только некоммерческим использованием; более новые бесплатные мозаики 2018–2025 имеют ограничение NC-SA. На карте показывается атрибуция EOxCloudless, EOX IT Services GmbH и изменённых данных Copernicus Sentinel 2016–2017. Интеграция не требует API-ключа и не использует Google Maps.

Спутниковая мозаика 2016 года может заметно устареть относительно текущего состояния поля и не годится для оперативной оценки посевов. Подложки нужны для визуального контекста; доступность тайлов зависит от внешних сервисов и интернета, их условия могут меняться. Проверяйте лицензии и ограничения поставщиков перед коммерческим развёртыванием.

Публичный tile-сервис OpenStreetMap и CDN Leaflet/Leaflet.Draw требуют доступа к интернету. Поля не отправляются на сервер и не синхронизируются между браузерами/устройствами.

## Дальнейшее развитие

Слой сохранённых полей отделён от базовой подложки; преобразование строк Supabase в GeoJSON изолировано в функциях преобразования, а загрузка и CRUD-вызовы вынесены в отдельные обработчики. Это оставляет точки расширения для импорта/экспорта GeoJSON, редактирования геометрии и будущей авторизации.

## Карта и атрибуция

Подложка использует стандартные тайлы OpenStreetMap с обязательной атрибуцией на карте. Перед широким развёртыванием проверьте актуальные требования и лимиты публичного tile-сервиса OSM.
