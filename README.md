# Менеджер полей

Минимальный адаптивный веб-каркас для карты и учёта сельскохозяйственных полей. Интерфейс приложения на русском языке.

## Запуск

Откройте `index.html` в браузере или запустите локальный статический сервер из этой папки, например:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`. Leaflet, OpenStreetMap tiles и шрифты загружаются через CDN, поэтому для карты нужен доступ в интернет.

## Текущий каркас

- `index.html` — семантическая разметка приложения и подключение Leaflet 1.9.4.
- `style.css` — адаптивная компоновка, панель инструментов, карта и пустая карточка поля.
- `app.js` — создание карты, добавление временной метки поля кликом по карте и состояние интерфейса.

Метки хранятся только в памяти страницы и исчезают после перезагрузки. Геометрия поля и его площадь пока не задаются. Панель слоёв и поиск пока служат интерфейсными заготовками.

## Дальнейшее развитие

Слои карты отделены от интерфейса, данные полей собраны в отдельном массиве состояния, а отображение сведений вынесено в `showField`. Это оставляет точки расширения для спутникового tile layer, загрузки/выгрузки GeoJSON и полигонального редактирования (например, отдельным Leaflet-плагином). Для сохранения данных можно добавить адаптер хранилища с локальной реализацией и позднее заменить его интеграцией с Supabase. Авторизация и серверная часть в этом каркасе отсутствуют.

## Карта и атрибуция

Подложка использует стандартные тайлы OpenStreetMap с обязательной атрибуцией на карте. Перед широким развёртыванием проверьте актуальные требования и лимиты публичного tile-сервиса OSM.
